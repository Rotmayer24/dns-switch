# Смена DNS (dns-switch)

Плагин для AngelOS. Переключает DNS текущего соединения одним кликом.
Работает через NetworkManager (`nmcli`), без root — через polkit.

## Возможности

- Кнопка на панели (баре) с текущим тегом DNS (`1.1.1`, `8.8.8`, `9.9.9`, `★`)
- Попап с выбором: Авто (DHCP), Cloudflare, Google, Quad9, AdGuard, Яндекс, Свой
- Свой DNS — поля IPv4/IPv6 в настройках (через запятую), сохранение в профиль
- Автоматическое определение текущего сервера по факту `resolv.conf`
- Работает в обеих темах (пиксель / Golden Gate) и в раю/аду

## Установка

**Локально (без каталога):**
```bash
cp -a ~/dns-switch ~/.config/angelos/plugins/dns-switch
# затем в Настройках → Плагины нажать ↻ или angelos restart
```

**Из ZIP (через загрузчик angelOS):**
Импортируйте `dns-switch-root.zip` — в архиве `manifest.json` в корне, всё остальное рядом.

**Из GitHub Release:**
Подключите репозиторий как `source` в `plugins.json` registry.

## Использование

1. Нажмите кнопку ☁ на панели.
2. Выберите провайдер из списка — применяется сразу (reapply, Wi-Fi не рвётся).
3. Для своего набора: Настройки → Плагины → Смена DNS → заполните IPv4/IPv6.

## Техническое

- Сервис: `Dns.qml` (singleton) — читает `nmcli`, хранит состояние
- Применение: `nmcli con mod <профиль>` → `nmcli device reapply <устройство>`
- Учитывает `ipv6.method` (если `disabled` — IPv6 пропускается, иначе ошибка `nmcli`)
- Нет внешних зависимостей кроме `NetworkManager` (обычно уже есть)

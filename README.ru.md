# Смена DNS (dns-switch)

Плагин для AngelOS. Переключает DNS текущего соединения одним кликом.
Работает через NetworkManager (`nmcli`), без root: за права отвечает polkit.

## Возможности

- Кнопка на панели с текущим тегом (`1.1.1`, `8.8.8`, `9.9.9`; для своего DNS первый IPv4-адрес, а если IPv4 нет, то `★`)
- Попап с выбором: Авто (DHCP), Cloudflare, Google, Quad9, AdGuard, Яндекс и ваши записи
- Свой DNS: сколько угодно именованных записей (IPv4/IPv6 через запятую) в настройках плагина, каждая показывается в попапе под своим именем
- Текущие серверы определяются по факту из NetworkManager (`nmcli dev show`), а не по сохранённому флагу
- Работает в обеих темах (пиксель / Golden Gate) и в раю/аду

## Установка

**Локально (без каталога):**
```bash
cp -a ~/dns-switch ~/.config/angelos/plugins/dns-switch
# затем в Настройках → Плагины нажать ↻ или angelos restart
```

**Из ZIP (через загрузчик angelOS):**
Импортируйте `dns-switch-root.zip` (`manifest.json` и `qmldir` лежат в корне архива).

**Из GitHub Release:**
Подключите репозиторий как `source` в реестре `plugins.json`.

## Использование

1. Нажмите кнопку ☁ на панели.
2. Выберите провайдера из списка. Применяется сразу (`nmcli device reapply`, Wi-Fi не рвётся).
3. Свой DNS: Настройки → Плагины → Смена DNS → заполните имя и IPv4/IPv6 → «Сохранить и включить» (или «Только сохранить»). Записями можно управлять в списке «Мои DNS» (Изменить / Удалить).

## Техническое

- Сервис: `Dns.qml` (singleton, объявлен в `qmldir` как `singleton Dns 1.0 Dns.qml`). Читает `nmcli`, применяет через argv, без shell
- Применение: `nmcli con mod <профиль>`, затем `nmcli device reapply <устройство>`; при неудаче соединение переподключается
- Если `ipv6.method` равен `disabled`, IPv6-часть пропускается (то же для IPv4)
- Свои записи хранятся в настройках плагина в виде JSON-списка
- Нет внешних зависимостей, кроме `NetworkManager` (обычно уже установлен)
